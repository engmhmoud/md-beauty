## New here?

md-beauty shows plain markdown files in a clean, readable style. Open your own files above, or look around first:

- [Getting started](getting-started.md): what the workspace does, and the command line tool for publishing your notes as a website
- [Callouts and tags](guide/01-callouts-and-tags.md): how plain blockquotes and `[MUST]` become colored boxes and pills
- [Lists, code and answers](guide/02-lists-code-answers.md): GitHub-style lists, code blocks and fold-out answers

> **Tip:** in Chrome or Edge, install this page as an app (the button above, or the install icon in the address bar). It then works offline, and `.md` files get an **Open with → md-beauty** choice on your computer.
